# 雾霾探测系统 - Uniapp 实现

## 1.项目简介
这是一个基于 Uniapp 框架开发的雾霾探测系统，主要功能包括实时天气信息获取、用户位置定位以及温湿度数据可视化展示。系统通过集成第三方 API 服务，为用户提供全面的环境监测数据。

## 2.主要功能模块
### 1.天气获取模块

实时获取当前天气状况

显示空气质量指数 (AQI)

### 2.地图定位模块

显示用户当前位置

地图标记环境监测点

默认使用高德地图 API

### 3.数据可视化模块

温湿度历史数据折线图展示

数据趋势分析

直观的可视化界面

## 3.快速食用指南
### 1. 准备工作
在开始使用前，您需要申请以下 API 密钥：

天气 API 密钥

高德地图 API 密钥 (或您选择的其他地图服务)

### 2. 配置步骤
天气 API 配置
打开 index.vue 文件

使用 Ctrl+F 搜索 key 关键词

将找到的 placeholder 替换为您申请的天气 API 密钥

确保同时更新 API 接口的 URL 地址

地图 API 配置
打开 location.js 文件

找到 key 字段

替换为您申请的地图 API 密钥

(可选) 如需更换地图服务提供商，需相应修改相关代码

### 3.收尾步骤

导入uniapp官方IDEHBuilderX运行即可
